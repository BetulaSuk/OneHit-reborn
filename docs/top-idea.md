# One Hit: 一键唤起的轻量信息缓存区

为用户提供高效信息展示/任务提醒，用极简界面和最少交互需求提升人类的“缓存命中”。

## 概念

在最少页面元素下展示最有效信息。具有现代风格ui和轻量流畅动画的多窗口操作方式。

信息与任务等价，表现为一个组件，默认结构为`核心文本+图片icon+标签`。

## 核心功能：OneHit浮窗

非焦点时为最小浮窗，无header和footer，仅仅展示当前置顶信息组件。

双击变为详细浮窗，不大于屏幕的1/4，仅展示信息列表。双击其header缩回。

### 信息拖动：标签

长按并拖动信息组件时，浮窗变黯淡，在**浮窗范围外**出现半透明拓展选区排布，每个选区对应一个标签，将信息拖至某选区以添加对应标签，添加成功后信息组件回到原位，拓展选区消失。

默认标签：

- 上浮/下沉：一个选区，拖入切换状态。下沉状态显示变黯淡，不会再显示在最小浮窗中，在任务列表中排在上浮任务之后
- 时间标签：方形选区，拖入信息组件后展示以一小时为周期的圆形进度条，类似apple-fitness
  - 用户可 使用鼠标滚轮/拖动进度条末端的圆形件 来调节时间，最多12h
  - 进度条超出一周时将超出的部分换新的颜色显示，在0进度附近颜色渐变过渡
  - 圆形进度条的上方展示对应信息组件，下方用hh:mm同步展示当前进度条代表的时间，可以直接滚动hh或mm的数字来设置时间
  - 已具有时间标签的组件再次拖入选区可重新调整时间
  - 具有时间标签的信息组件在最小浮窗/任务列表中显示时，其背景色将形成绿色倒计时进度条，并在右侧显示剩余时间
  - 在最小浮窗和任务列表中点击剩余时间可暂停/继续倒计时。暂停时背景色进度条为黄色；切换状态时有暂停/播放图标的动画
  - 倒计时结束时该信息组件红色高亮。下沉的组件自动停止倒计时，不再具备时间标签的相关交互行为
  - 可选择标签类型：Reminder/Timer
    - Timer：进入最小浮窗中将自动开始倒计时，不再展示时自动暂停倒计时；用户手动改变的状态不被自动更改
    - Reminder：不手动暂停则会一直倒计时；若倒计时结束的组件不在最小浮窗中，则将其展示在浮窗上下侧以提醒用户
- 详细：具有该标签的组件展示在最小浮窗中时将使浮窗变大，以展示详细信息。具体大小可配置

### 信息滚动

小型浮窗：滚动切换展示的信息组件

- 鼠标悬浮在其上时会在其下方展示部分信息列表，此时浮窗大小不变，多出的信息组件半透明显示在浮窗上下，越远处信息越透明，最多展示5条信息（可配置），不会展示有下沉标签的信息
- 鼠标滚轮滚动则信息列表滚动，停下后鼠标左键点击组件则最小浮窗会改为展示新选中的组件，该组件在列表中也将置顶
- 滚动列表的两端将有用于添加新信息的绿色选框
- 按下鼠标中键列表快速滚动回原位置

信息列表：正常的列表滚动

- 按下鼠标中键列表快速滚动回原位置

### 信息新建/编辑

小型浮窗：右键信息组件时扩大浮窗直接进入信息文本编辑

由于小型浮窗内的信息组件一定在列表顶，向下滚动才是选择列表中已有的信息。若向上滚动或向下滚动到列表底，会显示一个与信息组件大小相同的绿色选框，左键选中会新建信息，进入小型浮窗的信息编辑状态

信息列表：双击信息组件在左/右侧弹出分离的详细编辑页面

- 列表滚动时该页面跟随其信息移动，信息不可见时编辑页面也收回，信息再次可见时不自动展开编辑页面
- 编辑页面展示并可修改信息组件的全部数据，如文本、图片icon、标签

将外部图片文件/url拖拽至信息组件可将其设置为图片icon，需要预处理、压缩和裁剪图片文件。选中组件并执行粘贴时，若粘贴内容为文本则将其添加进信息尾部，若为图片则替换图片icon

## 实现

使用flutter作为ui库，信息组件的实现需要独立。预留好接口以便用户修改配置和安装自定义插件。
